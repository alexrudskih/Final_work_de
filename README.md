#### Проверка качества данных

Проверка качества данных осуществлена в пункте 4 [ноутбука](./final_work_de.ipynb) с помощью готового скрипта с набором проверок [data_quality_check.sql](./data_quality_check.sql). Каждая проверка по результатам запуска создает 2 типа строк:
* T - содержит информацию об общем количестве проверенных строк, количестве ошибочных строк и уровне качества данных, который определяется следующим образом - 1-(кол-во проверенных строк)/(кол-во ошибочных). Получаем долю верных данных.
* R - сами ошибочные строки.

Для строк R основной атрибут это invoice_id, также зарезервированы поля для дополнительных данных kv1, kv2, kv3 и kv4, в которые можно размещать дополнительные атрибуты.

В каждой строке заполняется поле date_check с указанием момента запуска проверки.

Для примера изменена проверка DQ_2 таким образом, чтоб она давала срабатывания. Условно она считает, что рейтинг больше 9 является не корректным.
